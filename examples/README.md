# Examples

`sample-report.md` / `sample-report.json` are **real** outputs of

```bash
netdoctor report --md examples/sample-report.md --json examples/sample-report.json
```

generated on 2026-10-08 on a build server **outside Iran** (behind a fake-IP egress proxy).
They show the report format. They are *not* representative of connectivity from Iran:
Iranian resolvers only answer Iranian networks, and many Iranian mirrors refuse foreign clients.
